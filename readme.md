
# Boutique React

**Il faut réaliser cette commande**

```bash
npm install; npm run build; xdg-open dist/index.html
```

J'ai rajouté en plus :
- Une page de Paiement qui vérifie si la carte est valide
- Un cadeau mystère 
- Un ticket de caisse
- Un bouton retour

Les différents designs viennent du site [uiverse](https://uiverse.io/).
